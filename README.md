A **fun and interactive multiplayer Rock-Paper-Scissors game** built in Python. Play against the computer or with friends while keeping track of scores in real time!  

Perfect for **beginners learning Python** and practicing loops, conditionals, functions, and dictionaries.

---

##  Features
- Multiplayer support — 2 or more players  
- Real-time **scoreboard tracking**  
- Randomized player turns  
- Win/Tie/Loss results with instant updates  
- Beginner-friendly Python console application  

---

##  How to Run
1. Make sure **Python 3** is installed  
2. Clone this repository or download the folder  
3. Open terminal in the project folder  
4. Run:

```bash
python rps.py 

```
